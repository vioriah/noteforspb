# 🌊 ФортранЛаб

Блокнот в стиле Google Colab и тренажёр по **Фортрану** для студентов-океанологов (2 курс, дисциплина «Программирование»).

- **Настоящий запуск кода.** Каждая ячейка компилируется `gfortran` (с проверками `-fcheck=all -Wall`) и выполняется на сервере, с вводом (stdin) и файлами данных.
- **Курс из 17 уроков и 57 задач с автопроверкой.** Переменные, типы и формулы (отдельный урок-практикум по дробям, корням, степеням и приоритетам операций) → ветвления и циклы → массивы, процедуры, модули, файлы → численные методы → океанологический практикум (EOS-80, скорость звука, частота Вяйсяля–Брента, обработка профиля CTD).
- **Подсказки на русском** к типичным ошибкам компилятора и выполнения, подсветка строк с ошибками.
- **Блокноты как в Colab:** ячейки кода и текста (markdown), Shift+Enter, «Выполнить всё». Модули в ячейках выше автоматически подключаются к ячейкам ниже.
- **Файлы и графики:** панель файлов блокнота; файлы, которые записала программа, можно посмотреть, скачать или сохранить в блокнот. Графики по числовым столбцам вывода, включая режим «вертикальный профиль» (глубина вниз).
- Прогресс и блокноты хранятся в браузере (localStorage), есть экспорт/импорт.

## Запуск

Нужны **Node.js ≥ 18** и **gfortran**. Сторонних npm-зависимостей нет.

```bash
# Ubuntu/Debian
sudo apt install gfortran nodejs
# macOS
brew install gcc node

node server.js        # http://localhost:8080
```

Переменные окружения: `PORT` (8080), `RUN_TIMEOUT_MS` (5000 — лимит времени работы программы), `MAX_PARALLEL` (число одновременных компиляций), `FC` (компилятор, по умолчанию `gfortran`), `ALLOW_SHELL=1` (разрешить `execute_command_line`/`system`; по умолчанию запрещены).

### Windows без WSL

1. Установите **Node.js LTS**: https://nodejs.org (установщик, все галочки по умолчанию).
2. Установите **MSYS2**: https://www.msys2.org (установщик). Откройте из меню Пуск **MSYS2 UCRT64** и выполните: `pacman -S mingw-w64-ucrt-x86_64-gcc-fortran` (на вопросы отвечайте `Y`).
3. Добавьте `C:\msys64\ucrt64\bin` в переменную среды `Path` (Пуск → «Изменение системных переменных среды» → Переменные среды → Path → Изменить → Создать).
4. Откройте **новое** окно PowerShell и проверьте: `gfortran --version` и `node --version`.
5. В папке проекта: `node server.js`, затем http://localhost:8080.

На Windows лимиты памяти не применяются (остаётся таймаут), а программы линкуются статически.

### Docker

```bash
docker compose up --build    # http://localhost:8080
```

`docker-compose.yml` уже содержит ограничения для запуска чужого кода: файловая система только для чтения, лимиты памяти, процессов и CPU, без capabilities.

## Безопасность

Сервер компилирует и запускает **произвольный код**. Внутри уже есть ограничения: таймаут, `prlimit` на процессорное время, память и размер файлов, отдельная временная папка на каждый запуск, лимит размера вывода, запрет вызовов оболочки. Но **это не песочница**. Для публичного развёртывания запускайте только в контейнере (см. `docker-compose.yml`), лучше на отдельной машине. Для занятий в группе можно поднять сервер в локальной сети.


### API

`POST /api/run`

```json
{
  "sources": [{ "name": "main.f90", "content": "program p ... end program p" }],
  "files":   [{ "name": "ctd.txt", "content": "..." }],
  "runs":    [{ "stdin": "3 4\n", "files": [] }]
}
```

Ответ: `{ compile: { ok, output }, runs: [{ stdout, stderr, exitCode, timedOut, timeMs, files }] }`. Программа компилируется один раз и запускается для каждого элемента `runs`, каждый раз в чистой папке. `files` в ответе — файлы, которые программа создала или изменила.

## Как добавить или изменить урок

Урок — это markdown-файл в `public/lessons/` и строка в `index.json`. Особые блоки:

````markdown
```fortran            ← исполняемая ячейка кода
program demo
  print *, 'hi'
end program demo
```
```stdin              ← ввод для предыдущей ячейки
42
```
```f90                ← фрагмент кода в тексте (не запускается)
```
```file data.txt      ← файл данных урока (доступен программам)
1 2 3
```

~~~task
title: Название задачи
---
Условие (markdown). Формулы — в $...$: $x_i$, $10^-5$.
@starter
program main
end program main
@solution
...эталонное решение...
@hint
Подсказка (их может быть несколько)
@file common.txt        ← общий файл задачи (до первого @test)
...
@test название теста
@stdin
3 4
@file per_test.txt      ← файл только для этого теста
...
@expect
7
@expectfile out.txt     ← какой файл должна записать программа
...
~~~
````

**Как сравнивается ответ.** Если ожидаемый вывод состоит только из чисел, сравниваются только числа: подписи в выводе студента игнорируются. Допуск определяется записью эталона: `3.14` означает «совпадает после округления до сотых», целое `7` — точное совпадение. Иначе вывод сравнивается по словам без учёта регистра.

После правок запустите проверку:

```bash
npm run verify                         # весь курс
node scripts/verify-lessons.js 05-loops --print   # один урок, с выводом эталонов
```

Ячейку, которая специально содержит ошибку, пометьте в первой строке комментарием `! (с ошибкой)`.

## Источники

Курс опирается на учебники Бартеньева, Горелика, Немнюгина и Стесик, Chapman, Metcalf–Reid–Cohen. Формулы свойств морской воды взяты из UNESCO (Fofonoff & Millard, 1983) и Mackenzie (1981). Реализация проверена по опубликованным контрольным значениям. Полный список — в приложении: «Справочник → Литература и источники».
