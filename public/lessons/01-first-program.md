# 1. Первая программа на Фортране

## Зачем океанологу Фортран

Фортран (FORmula TRANslation, 1957) — первый язык высокого уровня, созданный специально для научных расчётов. Он и сегодня остаётся основным языком численного моделирования океана и атмосферы. На Фортране написаны модели океана **NEMO**, **MOM**, **ROMS**, модели ветрового волнения **WAVEWATCH III** и **SWAN**, климатическая модель ИВМ РАН **INMCM**, модель погоды **WRF**. Если вы будете работать с моделями или старым научным кодом, вы почти наверняка встретите Фортран.

Мы изучаем **современный Фортран** (стандарты Fortran 90/95/2003/2008): свободная форма записи, модули, массивы как единое целое. Старый Фортран 77 с фиксированными колонками встречается в унаследованном коде, но писать на нём новые программы не нужно.

## Как программа превращается в результат

1. Вы пишете **исходный текст** — файл `program.f90`.
2. **Компилятор** (у нас — `gfortran`) переводит его в машинный код и создаёт исполняемый файл. На этом этапе находятся *синтаксические* ошибки.
3. Исполняемый файл **запускается**: читает данные, считает, печатает результат. На этом этапе возникают *ошибки выполнения* (деление на ноль, выход за границы массива…).

На своём компьютере это выглядит так:

```f90
$ gfortran hello.f90 -o hello
$ ./hello
```

Здесь оба шага выполняет кнопка **▶** слева от ячейки (или `Shift+Enter`). Попробуйте:

```fortran
program hello
  implicit none
  print *, 'Привет, океан!'
end program hello
```

## Структура программы

```f90
program имя_программы
  implicit none
  ! 1) объявления переменных
  ! 2) исполняемые операторы
end program имя_программы
```

- `program имя` и `end program имя` — начало и конец главной программы. Имя пишется латиницей, без пробелов.
- `implicit none` — **обязательно пишите всегда**. Эта строка запрещает «неявную типизацию»: по старому правилу переменные на `i…n` считались целыми, остальные — вещественными. Без `implicit none` опечатка в имени переменной незаметно создаёт новую переменную, и программа молча считает неправильно.
- `!` — начало **комментария**: всё до конца строки компилятор игнорирует.
- **Регистр букв не важен**: `PRINT`, `Print` и `print` — одно и то же, как и переменные `Temp` и `temp`.
- Длинную строку можно перенести, поставив `&` в конце.

## Вывод на экран: `print`

`print *, список` печатает значения через пробелы. Звёздочка означает «формат по умолчанию» (*list-directed*). Строки пишутся в одинарных или двойных кавычках.

```fortran
program first_print
  implicit none
  print *, 'Глубина Марианской впадины, м:', 10994
  print *, 'Площадь Мирового океана, млн км2:', 361.3
  print *, 'Средняя солёность, епс (psu):', &   ! перенос строки
           35.0
  print *          ! пустая строка
  print *, 2 + 2, 7 * 6, 1.5 / 3.0
end program first_print
```

Обратите внимание: `print *` сам выбирает ширину полей, поэтому перед числами появляются пробелы, а вещественные числа печатаются со многими знаками. Как управлять видом вывода, разберём в уроке 3.

## Переменные — первое знакомство

Переменная — именованная ячейка памяти. Её нужно **объявить** до первого исполняемого оператора. Присваивание записывается знаком `=`:

```fortran
program knots
  implicit none
  real :: speed_knots, speed_ms

  speed_knots = 12.0                        ! скорость судна в узлах
  speed_ms = speed_knots * 1852.0 / 3600.0  ! 1 узел = 1 морская миля (1852 м) в час
  print *, 'Скорость, м/с:', speed_ms
end program knots
```

## Ошибки компиляции — это нормально

Компилятор очень строг. Запустите ячейку ниже: в ней не объявлена переменная. Посмотрите на сообщение, номер строки (подсвечен слева) и подсказку под ним.

```fortran
! (с ошибкой) — эта ячейка специально написана с ошибкой
program broken
  implicit none
  real :: depth
  depth = 4000.0
  presure = depth * 1.0e-1   ! опечатка в имени переменной
  print *, presure
end program broken
```

Сообщение `Symbol 'presure' at (1) has no IMPLICIT type` означает: «переменная не объявлена». Исправьте опечатку прямо в ячейке (`pressure`, а заодно объявите её) и запустите снова.

> **Как читать сообщения gfortran.** Первая строка вида `main.f90:6:10:` — это файл, строка 6, позиция 10. Затем показан фрагмент кода, а цифра `1` под ним указывает место ошибки. Последняя строка — `Error: …` (ошибка) или `Warning: …` (предупреждение: программа соберётся, но, возможно, делает не то, что вы задумали).

~~~task
title: Морские мили
---
Морская миля равна **1852 м**. Выведите, сколько метров в 15 морских милях (одно число).

Подпись к числу печатать можно: проверяются только числа.
@starter
program miles
  implicit none

end program miles
@solution
program miles
  implicit none
  print *, 15 * 1852
end program miles
@hint
Арифметику можно писать прямо внутри `print`: `print *, 2 * 3`.
@test
@expect
~~~

~~~task
program knots
  implicit none

  v_knots = 12.0
~~~
