# 4. Ветвления: `if` и `select case`

## Логические выражения

| Операция | Современная запись | Старая запись |
|---|---|---|
| равно | `==` | `.eq.` |
| не равно | `/=` | `.ne.` |
| меньше / меньше или равно | `<`  `<=` | `.lt.`  `.le.` |
| больше / больше или равно | `>`  `>=` | `.gt.`  `.ge.` |
| и, или, не | `.and.`  `.or.`  `.not.` | |

Результат сравнения имеет тип `logical`. Его можно сохранить в переменной:

```f90
logical :: is_cold
is_cold = (t < 4.0) .and. (depth > 200.0)
```

> **Вещественные числа не сравнивают на точное равенство.** `0.1 + 0.2 == 0.3` даёт `.false.` из-за ошибок округления. Пишите `abs(a - b) < 1.0e-6`.

## Оператор `if`

Короткая форма — один оператор, без `then`:

```f90
if (t < -1.9) print *, 'Возможно образование льда'
```

Полная форма:

```f90
if (условие1) then
  ...
else if (условие2) then
  ...
else
  ...
end if
```

Условия проверяются **сверху вниз**, выполняется первая подходящая ветка.

```fortran
program water_type
  implicit none
  real :: t
  read(*,*) t
  if (t < 0.0) then
    print *, 'Переохлаждённая или солёная вода ниже 0 °C'
  else if (t < 4.0) then
    print *, 'Холодная вода'
  else if (t < 20.0) then
    print *, 'Умеренная'
  else
    print *, 'Тёплая'
  end if
end program water_type
```
```stdin
2.7
```

Поменяйте число в поле ввода и запустите снова.

## Оператор `select case`

Удобен, когда выбор делается по значению **целого**, **символьного** или **логического** выражения (для `real` использовать нельзя!):

```fortran
program seasons
  implicit none
  integer :: month
  read(*,*) month
  select case (month)
  case (12, 1, 2)
    print *, 'Зима'
  case (3:5)              ! диапазон 3..5
    print *, 'Весна'
  case (6:8)
    print *, 'Лето'
  case (9:11)
    print *, 'Осень'
  case default
    print *, 'Нет такого месяца'
  end select
end program seasons
```
```stdin
7
```

## Логические переменные и вложенность

```fortran
program leap
  implicit none
  integer :: y
  logical :: is_leap
  read(*,*) y
  is_leap = (mod(y, 4) == 0 .and. mod(y, 100) /= 0) .or. mod(y, 400) == 0
  if (is_leap) then
    print *, y, '— високосный, в году 366 дней'
  else
    print *, y, '— обычный, в году 365 дней'
  end if
end program leap
```
```stdin
2024
```

~~~task
title: Квадратное уравнение
---
Прочитайте коэффициенты $a ≠ 0$, $b$, $c$ уравнения $ax² + bx + c = 0$.

- если корней два — выведите их **по возрастанию** в одной строке;
- если корень один (дискриминант равен нулю) — выведите его;
- если вещественных корней нет — выведите текст `нет корней`.
@starter
program quadratic
  implicit none
  integer, parameter :: dp = kind(1.0d0)
  real(dp) :: a, b, c, d

  read(*,*) a, b, c

end program quadratic
@solution
program quadratic
  implicit none
  integer, parameter :: dp = kind(1.0d0)
  real(dp) :: a, b, c, d, x1, x2
  read(*,*) a, b, c
  d = b**2 - 4.0_dp * a * c
  if (abs(d) < 1.0e-12_dp) then
    print *, -b / (2.0_dp * a)
  else if (d > 0.0_dp) then
    x1 = (-b - sqrt(d)) / (2.0_dp * a)
    x2 = (-b + sqrt(d)) / (2.0_dp * a)
    print *, min(x1, x2), max(x1, x2)
  else
    print '(A)', 'нет корней'
  end if
end program quadratic
@hint
Если $a < 0$, то формула $(-b - √D) / 2a$ даёт **больший** корень. Используйте `min` и `max`.

@test

@expect
~~~

~~~task
title: Високосный год
---
Прочитайте год и выведите `да`, если он високосный, и `нет` — если нет.

Год високосный, если он делится на 4 и не делится на 100, **или** делится на 400.

program leap_year
  implicit none
  integer :: y

program leap_year
  implicit none

  read(*,*) y
  if ((mod(y, 4) == 0 .and. mod(y, 100) /= 0) .or. mod(y, 400) == 0) then
    print '(A)', 'да'
  else
    print '(A)', 'нет'
  end if
end program leap_year
~~~
