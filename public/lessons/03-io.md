# 3. Ввод, вывод и форматы

## Ввод: `read`

```f90
read(*,*) a, b, c      ! первая * — стандартный ввод (клавиатура), вторая * — свободный формат
```

При свободном (*list-directed*) вводе числа разделяются пробелами, запятыми или переводами строк. Один оператор `read` начинает чтение **с новой строки** и, если чисел не хватает, читает следующие строки. Остаток строки после прочитанных значений пропускается.

```fortran
program read_list
  implicit none
  real :: t, s
  integer :: station
  read(*,*) station
  read(*,*) t, s
  print *, 'Станция', station, ': T =', t, ' S =', s
end program read_list
```
```stdin
17
4.25, 34.92
```

> Дробную часть отделяет **точка**: `3.5`, а не `3,5`. Запятая — это разделитель, поэтому `3,5` прочитается как два числа: 3 и 5.

## Вывод: `print` и `write`

```f90
print *, x, y              ! свободный формат, стандартный вывод
write(*,*) x, y            ! то же самое
write(*,'(F8.3)') x        ! с явным форматом
write(10,'(F8.3)') x       ! в файл, открытый как устройство 10 (урок 10)
```

## Форматы

Формат — это строка в скобках, перечисляющая **дескрипторы** для каждого выводимого значения:

| Дескриптор | Смысл | Пример | Результат |
|---|---|---|---|
| `Iw` | целое в `w` позициях | `I5` для 42 | `···42` |
| `Iw.m` | целое, минимум `m` цифр (с нулями) | `I2.2` для 5 | `05` |
| `Fw.d` | вещественное: `w` позиций, `d` после точки | `F8.3` для 3.14159 | `···3.142` |
| `Ew.d` | экспоненциальная форма | `E12.4` для 1234.5 | `··0.1235E+04` |
| `ESw.d` | научная форма (одна цифра до точки) | `ES11.3` для 1234.5 | `··1.235E+03` |
| `A`, `Aw` | строка | `A` | как есть |
| `nX` | `n` пробелов | `2X` | `··` |
| `/` | перевод строки | | |
| `Lw` | логическое (T/F) | `L2` | `·T` |

(`·` обозначает пробел.) Дескрипторы можно повторять: `3F8.2` = `F8.2,F8.2,F8.2`, а группы — так: `2(I4, F7.2)`.

```fortran
program formats
  implicit none
  real :: t = 12.3456, s = 34.98765
  integer :: depth = 150
  write(*,'(A, I5, A)') 'Глубина:', depth, ' м'
  write(*,'(A, F7.2, 2X, A, F7.3)') 'T =', t, 'S =', s
  write(*,'(3F10.4)') t, s, t + s
  write(*,'(ES12.4)') 6.02214076e23
  write(*,'(I2.2, A, I2.2, A, I4)') 5, '.', 3, '.', 2026
  write(*,'(F5.1)') 123456.7        ! не помещается — будут звёздочки
  write(*,'(A)') 'Строка 1', 'Строка 2'  ! формат используется заново для каждого значения
end program formats
```

> Если число не помещается в поле, вместо него печатаются **звёздочки** `*****`. Это не ошибка программы, а сигнал увеличить ширину поля.

Формат можно вынести в отдельный оператор с меткой (старый стиль, часто встречается в чужом коде):

```f90
      write(*, 100) t, s
100   format('T =', F7.2, '  S =', F7.3)
```

## Строки

```fortran
program strings
  implicit none
  character(len=20) :: sea
  character(len=:), allocatable :: msg
  sea = 'Белое'                       ! дополняется пробелами до 20 символов
  msg = trim(sea) // ' море'          ! // — склейка строк, trim убирает хвостовые пробелы
  print *, '[' // sea // ']'
  print *, '[' // msg // ']'
  print *, 'длина:', len(sea), len_trim(sea)
  print *, 'позиция "море":', index(msg, 'море')
end program strings
```

Строки в UTF-8: русская буква занимает **два** байта, поэтому `len_trim('Белое')` = 10. Для имён файлов и служебных строк лучше использовать латиницу.

### Число → строка (внутренняя запись)

Оператор `write` умеет писать не только на экран, но и **в строковую переменную** — так удобно составлять имена файлов:

```fortran
program internal_write
  implicit none
  character(len=32) :: fname
  integer :: st
  st = 7
  write(fname, '(A, I3.3, A)') 'station_', st, '.txt'
  print *, trim(fname)
end program internal_write
```

title: Дата измерения
---
Прочитайте три целых числа — день, месяц и год — и выведите дату в формате `ДД.ММ.ГГГГ` (с ведущими нулями, без пробелов).

@starter
program date_fmt
  implicit none
  integer :: d, m, y

  read(*,*) d, m, y

@solution
program date_fmt
  implicit none
  integer :: d, m, y
  read(*,*) d, m, y
  write(*,'(I2.2, A, I2.2, A, I4.4)') d, '.', m, '.', y
end program date_fmt
@hint
Дескриптор `I2.2` печатает целое в 2 позициях и минимум 2 цифры, то есть с ведущим нулём.
@test
@stdin
5 3 2026
@expect
05.03.2026
@test
@stdin
31 12 1999
@expect
31.12.1999
@test
@stdin
1 1 2000
@expect
01.01.2000

~~~task
title: Градусы, минуты, секунды
---
Координаты станции записаны в десятичных градусах. Переведите **положительную** широту в градусы, минуты и секунды: выведите два целых числа (градусы, минуты) и секунды с одним знаком после точки.

**Пример.** `55.7558` → `55 45 20.9`.
@starter
program dms
  implicit none
  real :: lat
  integer :: deg, minutes
  real :: sec

  read(*,*) lat

end program dms
@solution
program dms
  implicit none
  real :: lat, rest
  integer :: deg, minutes
  real :: sec
  read(*,*) lat
  deg = int(lat)
  rest = (lat - deg) * 60.0
  minutes = int(rest)
  sec = (rest - minutes) * 60.0
  write(*,'(I0, 1X, I0, 1X, F0.1)') deg, minutes, sec
end program dms
@hint
Целая часть — `int(lat)`. Дробная часть, умноженная на 60, даёт минуты (опять берём целую часть), а остаток, умноженный на 60, — секунды.
@hint
`I0` и `F0.1` — «минимальная ширина»: число печатается без лишних пробелов.
@test
@stdin
55.7558
@expect
55 45 20.9
@test
@stdin
43.1056
@expect
43 6 20.2
@test
@stdin
69.5
@expect
69 30 0.0
~~~

title: Карточка станции
---
Прочитайте номер станции (целое), температуру и солёность (вещественные). Выведите **одну** строку вида

St 17: T = 4.25 C, S = 34.92

@starter
program card

  real :: t, s

program card
  implicit none

  real :: t, s
  read(*,*) st, t, s

end program card
@hint
Формат может чередовать строковые литералы и числа: `'(A, I0, A, F0.2, A, F0.2)'`.

17 4.25 34.92

St 17: T = 4.25 C, S = 34.92
